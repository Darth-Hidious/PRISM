### What I will build (plan, not yet executed)

**1. `crates/provenance/src/lib.rs` — make the store queryable for outcomes.**
- Enrich `ProvenanceStats` with outcome counts: add fields `ok_records: usize`, `error_records: usize`, plus a method that aggregates them. Change `stats()` from a single `SELECT COUNT(*)` to a grouped `SELECT status, COUNT(*) ... GROUP BY status` and fold the three buckets ("ok"/"error"/NULL) into the struct. (Existing `total_records` is preserved = ok+error+other; additive, no behavior break.)
- Add `pub async fn query_failures(&self, session_id: Option<&str>, limit: usize) -> Result<Vec<ProvenanceRecord>>` — `SELECT * ... WHERE status = 'error' [AND session_id=?] ORDER BY timestamp DESC LIMIT ?`. This is the direct "which runs failed?" query VS3 asks for. Reuses existing `row_to_record` + the `RECORD_COLS` ordering already documented at `lib.rs:505-507`.
- Both are pure additions to a stable store API; no existing caller breaks.

**2. `crates/agent/src/hooks.rs` — surface status/exit_code on the record-creation paths that currently omit it.**
The audit found the **LLM-turn** recorder (`agent_loop.rs:1041-1074`) and the **single-tool service executor** (`service.rs:348-383`) leave `status`/`exit_code` None. I'll wire `classify_for_provenance` (already exists at `hooks.rs:302-312`) into these two record builders so a failed LLM-call or externally-invoked tool is also classifiable — making "which runs failed" complete, not just tool-call-hook records. (Workflow/campaign paths stay as-is; they encode outcome in tags and are not tool runs. I'll note this honestly in the report.)

**3. `crates/agent/src/meta_tools.rs` — let `recall` surface outcome.**
`recall` (the agent-facing reader, `meta_tools.rs:436-535`) currently returns `id/tool_name/input/output/preview/score` but drops `status`/`exit_code`. I'll add `status` and `exit_code` to the recall payload JSON so the agent can reason over prior failures (e.g. "last time execute_python failed with exit_code -11"). Small additive change to the recall result shape.
